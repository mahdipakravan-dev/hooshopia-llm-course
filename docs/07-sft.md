# قسمت ۷: SFT؛ از «ادامه‌دهندهٔ متن» تا «دستیار»

مدل پیش‌آموزش‌دیده فقط متن رو ادامه می‌ده. اگه ازش بپرسی «پایتخت ایران کجاست؟» ممکنه جواب بده «پایتخت فرانسه کجاست؟»، چون توی داده‌اش سؤال‌ها پشت سر هم اومدن.
SFT با چند هزار مثال گفتگو بهش یاد می‌ده بعد از سؤال، جواب بنویسه.

## قالب چت (`llm/chat.py`)

```
<|user|>پایتخت ایران کجاست؟<|end|><|assistant|>پایتخت ایران تهرانه.<|end|>
```

مدل نقش‌ها رو نمی‌شناسه؛ فقط همین توکن‌های ویژه رو می‌بینه. این توکن‌ها رو از قسمت ۲ توی توکنایزر رزرو کرده بودیم.
موقع چت، متن رو تا `<|assistant|>` می‌دیم و مدل تا وقتی `<|end|>` بنویسه ادامه می‌ده.

## ماسک loss

```
توکن:    <|user|> پایتخت ... <|end|> <|assistant|> پایتخت ایران تهرانه . <|end|>
آموزش:     ✗       ✗       ✗     ✗        ✗          ✓     ✓     ✓    ✓    ✓
```

`build_example` هدف‌های خارج از جواب دستیار رو `-100` می‌کنه و `cross_entropy` با `ignore_index=-100` اون‌ها رو نادیده می‌گیره.
یعنی مدل یاد می‌گیره **جواب** بنویسه، نه اینکه ادای کاربر رو دربیاره. `<|end|>` هم جزو جوابه، تا مدل یاد بگیره کِی تموم کنه.

## آموزش (`llm/sft.py`)

همون حلقهٔ پیش‌آموزش، با این فرق‌ها:
- **LR خیلی کمتر** (پیش‌فرض `3e-5`) که دانش پیش‌آموزش از بین نره.
- بچ‌ها از گفتگوهای با طول متفاوت ساخته می‌شن؛ `collate` با `-100` پد می‌کنه.
- ارزیابی فقط روی توکن‌های جواب (`masked_loss`).

## اجرا

```bash
python -m llm.sft --ckpt checkpoints/small/ckpt.pt --data data/sample/sft.jsonl --out checkpoints/sft
python -m llm.chat_cli --ckpt checkpoints/sft/ckpt.pt
```

`data/sample/sft.jsonl` فقط ۲۴ گفتگوی نمونه‌ست تا فرمت رو ببینی. برای نتیجهٔ واقعی چند هزار گفتگوی فارسی لازمه:
دیتاست‌های گفتگوی فارسی موجود، ترجمهٔ دیتاست‌های انگلیسی، یا گفتگوهایی که خودت با یه مدل بزرگ‌تر می‌سازی و بازبینی می‌کنی. قبل از استفاده لایسنس هر دیتاست رو چک کن.

## نمایش جواب تکه‌تکه

هر حرف فارسی دو بایته و یه توکن ممکنه وسط یه حرف تموم بشه. `StreamDecoder` بایت‌های ناقص رو نگه می‌داره تا حرف کامل بشه، و بعد چاپش می‌کنه.
