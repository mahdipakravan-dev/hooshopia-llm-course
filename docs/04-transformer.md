# قسمت ۴: ترنسفورمر

مشکل bigram این بود که هر توکن فقط توکن قبلی رو می‌دید. ترنسفورمر به هر توکن اجازه می‌ده به **همهٔ** توکن‌های قبلی‌اش نگاه کنه.

```
ids ─► Embedding ─► [Block × n_layer] ─► RMSNorm ─► lm_head ─► logits
                        ├─ x = x + Attention(RMSNorm(x))
                        └─ x = x + MLP(RMSNorm(x))
```

## Self-Attention (`attention_manual`)

برای هر توکن سه بردار می‌سازیم: `q` (دنبال چی‌ام)، `k` (چی دارم)، `v` (چی منتقل می‌کنم).

```
scores = q · kᵀ / √d        شباهت هر توکن با بقیه
scores[آینده] = -∞          ماسک علّی: هیچ توکنی آینده رو نمی‌بینه
out = softmax(scores) · v    میانگین وزن‌دار v ها
```

ماسک علّی همون چیزیه که آموزش موازی رو ممکن می‌کنه: توی یه پنجرهٔ ۲۵۶ توکنی، ۲۵۶ پیش‌بینی هم‌زمان داریم و هیچ‌کدوم جواب رو از قبل نمی‌بینه.
تست `test_causal_mask_hides_the_future` همینو چک می‌کنه: عوض کردن توکن ۱۵ خروجی موقعیت‌های قبل از ۱۵ رو تغییر نمی‌ده.

در عمل از `F.scaled_dot_product_attention` استفاده می‌کنیم که همین محاسبه‌ست ولی خیلی سریع‌تر (و روی GPU با Flash Attention). تست `test_manual_attention_matches_sdpa` نشون می‌ده خروجی هر دو یکیه.

## Multi-Head

`n_embd` رو به `n_head` تکه تقسیم می‌کنیم و هر تکه attention جداگونهٔ خودش رو انجام می‌ده. هر head می‌تونه یه نوع رابطه رو یاد بگیره (دستوری، معنایی، فاصله‌ای). بعد خروجی‌ها کنار هم چیده می‌شن و از `proj` رد می‌شن.

## RoPE: جایگاه توکن‌ها

attention خودش ترتیب رو نمی‌فهمه. RoPE هر جفت از مؤلفه‌های `q` و `k` رو به اندازهٔ جایگاه توکن می‌چرخونه.
نتیجه: حاصل‌ضرب `q·k` فقط به **فاصلهٔ** دو توکن بستگی داره، نه جای مطلقشون (`test_rope_depends_only_on_distance`).

## بقیهٔ بلوک

- **MLP:** دو لایهٔ خطی با GELU بینشون (۴ برابر عرض). هر توکن جدا پردازش می‌شه.
- **Residual:** هر لایه چیزی به `x` *اضافه* می‌کنه، جایگزینش نمی‌کنه؛ این باعث می‌شه گرادیان تو مدل‌های عمیق راحت جریان پیدا کنه.
- **RMSNorm** قبل از هر زیرلایه (pre-norm) که آموزش پایدار بمونه.
- **Weight tying:** ماتریس embedding و `lm_head` یکیه؛ پارامتر کمتر، نتیجهٔ بهتر.
- **مقداردهی اولیه:** وزن‌ها با انحراف معیار ۰٫۰۲ و لایه‌های `proj` کوچیک‌تر، تا loss اولیه نزدیک `ln(V)` باشه.

## اجرا

```bash
python -m llm.model --data data/clean --tokenizer tokenizer.json --steps 500
```
