# قسمت ۱: داده

کیفیت مدل قبل از هر چیز به کیفیت داده بستگی داره. این قسمت متن خام رو به یه کورپوس تمیز و شاردشده تبدیل می‌کنه.

```
خواندن ──► نرمال‌سازی ──► فیلتر ──► حذف تکراری ──► شارد
read_documents  normalize    min_chars    sha1         train_*.jsonl
                             min_persian               val.jsonl
```

## نرمال‌سازی (`llm/normalize.py`)

یه کلمه می‌تونه با نویسه‌های یونیکد مختلف نوشته بشه؛ برای مدل این‌ها توکن‌های متفاوتن. پس همه رو یکی می‌کنیم:

| مشکل | مثال | بعد از نرمال‌سازی |
|---|---|---|
| حروف عربی | `يكي` | `یکی` |
| اعداد عربی | `١٢٣` | `۱۲۳` |
| اعراب | `بِسمِ` | `بسم` |
| کشیده (تطویل) | `ســـلام` | `سلام` |
| نیم‌فاصلهٔ کنار فاصله یا تکراری | `خوب ‌ ‌ بود` | `خوب بود` |
| نویسه‌های نامرئی (RLM، BOM و …) | | حذف |
| شکل‌های نمایشی عربی | `ﻻ` | `لا` (با NFKC) |

## فیلتر و حذف تکراری (`llm/data.py`)

- **کوتاه:** سندهای زیر ۴۰ نویسه چیزی یاد نمی‌دن.
- **غیرفارسی:** اگه کمتر از ۶۰٪ حروف فارسی باشه، کنار می‌ره (`persian_ratio`).
- **تکراری:** هش SHA-1 متنِ نرمال‌شده؛ هر متن فقط یک بار. متن تکراری باعث می‌شه مدل اون رو حفظ کنه.
- **val:** هر صدمین سند (و همیشه سند اول) می‌ره توی `val.jsonl`، تا بعداً بفهمیم مدل واقعاً یاد گرفته یا فقط حفظ کرده.

## اجرا

```bash
# دادهٔ نمونهٔ داخل ریپو
python -m llm.data --input data/sample/raw --out data/clean

# دادهٔ واقعی: ویکی‌پدیای فارسی از Hugging Face
pip install datasets
python -m llm.data --hf wikimedia/wikipedia --hf-config 20231101.fa --out data/clean
```

خروجی روی دادهٔ نمونه:

```
        seen  34
   too_short  2
 not_persian  1
   duplicate  2
        kept  29
```

`data/sample/raw` عمداً پر از مشکله (حروف عربی، اعراب، کشیده، متن انگلیسی، پاراگراف تکراری) تا اثر هر مرحله رو ببینیم.

## منابع دادهٔ فارسی برای آموزش واقعی

- ویکی‌پدیای فارسی: `wikimedia/wikipedia` با کانفیگ `20231101.fa`
- بخش فارسی FineWeb-2 (متن وب فیلترشده)
