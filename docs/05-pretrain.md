# قسمت ۵: پیش‌آموزش

حالا مدل رو روی کل کورپوس آموزش می‌دیم تا توکن بعدی رو پیش‌بینی کنه. حلقهٔ آموزش همون حلقهٔ قسمت ۳ـه؛ چیزهایی که اضافه می‌شه برای اینه که روی دادهٔ بزرگ و GPU واقعی سریع و پایدار کار کنه.

## ۱. داده روی دیسک

```bash
python -m llm.tokenize_data --data data/clean --tokenizer tokenizer.json --out data/tokens
```

کل کورپوس یک بار توکنایز می‌شه و به‌صورت یه آرایهٔ `uint16` روی دیسک ذخیره می‌شه (`train.bin`، `val.bin`).
موقع آموزش با `np.memmap` فقط همون پنجره‌هایی که لازمه از دیسک خونده می‌شن؛ پس کورپوس می‌تونه از RAM خیلی بزرگ‌تر باشه.

## ۲. بهینه‌سازی

| چیز | چرا |
|---|---|
| **AdamW**، `betas=(0.9, 0.95)` | استاندارد مدل‌های زبانی |
| **weight decay فقط روی ماتریس‌ها** | منظم‌سازی وزن‌ها، بدون دست زدن به وزن‌های RMSNorm |
| **gradient clipping** (نرم ۱) | جلوی جهش‌های ناگهانی loss رو می‌گیره |
| **warmup خطی + کاهش کسینوسی** | اول آروم شروع می‌کنیم، بعد LR کم‌کم تا `min_lr` پایین میاد (`lr_at`) |

## ۳. سرعت و حافظه

- **mixed precision:** روی GPU محاسبه‌ها با `bfloat16` انجام می‌شن (حافظهٔ نصف، سرعت بیشتر). کارت‌های قدیمی‌تر `float16` با `GradScaler` می‌گیرن.
- **gradient accumulation:** اگه بچ بزرگ توی حافظه جا نشه، چند بچ کوچیک پشت سر هم می‌ریم و گرادیان‌هاشون رو جمع می‌کنیم. بچ مؤثر = `batch_size × grad_accum`.
- **`torch.compile`:** کل مدل رو به یه کرنل بهینه کامپایل می‌کنه (`"compile": true`).

## ۴. ارزیابی و checkpoint

هر `eval_every` قدم، loss روی train و val با بچ‌های ثابت حساب می‌شه. هر وقت val بهتر شد، checkpoint ذخیره می‌شه (`checkpoints/<run>/ckpt.pt` همراه `tokenizer.json`).
اگه آموزش قطع شد، با `--set resume=true` از همون‌جا ادامه می‌ده.

## اجرا

```bash
# روی CPU با دادهٔ نمونه، فقط برای اینکه ببینیم همه‌چیز کار می‌کنه
python -m llm.pretrain --config configs/tiny.json

# روی GPU
python -m llm.pretrain --config configs/small.json
python -m llm.pretrain --config configs/small.json --set batch_size=16 grad_accum=2   # اگه حافظه کم اومد
```

| کانفیگ | پارامتر | سخت‌افزار |
|---|---|---|
| `tiny` | ~۰٫۱M | CPU، چند دقیقه |
| `small` | ~۳۰M | یه GPU با ۱۶ تا ۲۴ گیگ، ~۰٫۴ میلیارد توکن |
| `base` | ~۱۱۰M | یه GPU با ۸۰ گیگ، ~۲٫۶ میلیارد توکن |

قانون سرانگشتی: حدود ۲۰ توکن داده به ازای هر پارامتر. برای `small` یعنی دست‌کم ۶۰۰ میلیون توکن متن فارسی تمیز.
