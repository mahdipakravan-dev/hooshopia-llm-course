# قسمت ۰: نقشهٔ کار و راه‌اندازی

## کل مسیر

```
متن خام ──► داده‌ی تمیز ──► توکنایزر ──► پیش‌آموزش ──► SFT ──► سرو
 (01)          (01)           (02)       (03-06)      (07)    (08-09)
```

1. **داده:** متن فارسی جمع می‌کنیم، نرمال و تمیز می‌کنیم، تکراری‌ها رو حذف می‌کنیم.
2. **توکنایزر:** متن رو به عدد تبدیل می‌کنیم (BPE بایت‌محور).
3. **پیش‌آموزش:** مدل یاد می‌گیره توکن بعدی رو پیش‌بینی کنه. اول یه baseline ساده (bigram)، بعد ترنسفورمر.
4. **SFT:** با مثال‌های گفتگو، مدلِ «ادامه‌دهندهٔ متن» تبدیل می‌شه به «دستیار».
5. **سرو:** مدل رو پشت یه API محلی و یه رابط چت می‌ذاریم.

## ساختار ریپو

```
llm/        کد اصلی (هر قسمت یه یا چند ماژول اضافه می‌کنه)
tests/      تست هر ماژول
docs/       یادداشت هر قسمت
data/       دادهٔ نمونه (دادهٔ واقعی و خروجی‌ها کامیت نمی‌شن)
```

## اجرا

```bash
pip install -r requirements.txt
python -m llm.env
pytest -q
```

`llm.env` نشون می‌ده آموزش روی کدوم دستگاه انجام می‌شه: `cuda` (کارت گرافیک NVIDIA)، `mps` (مک با چیپ Apple) یا `cpu`.
تا قسمت ۴ همه‌چیز روی CPU هم اجرا می‌شه؛ برای پیش‌آموزش واقعی (قسمت ۵) GPU لازمه.

هر push روی گیت‌هاب، تست‌ها رو با GitHub Actions روی CPU اجرا می‌کنه.
